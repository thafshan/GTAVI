# 🎮 GTA VI Landing Page

A modern and immersive **GTA VI-inspired landing page** built with React, Tailwind CSS, GSAP, and Vite.

This project focuses on recreating the visual experience of a modern game promotional website while practicing **React component development, animations, responsive layouts, and interactive UI design**.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/thafshan/GTAVI.git
```

### 2. Navigate into the project

```bash
cd GTAVI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.

---

## 🏗️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
